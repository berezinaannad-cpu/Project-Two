# Люмен — браузерная микро-аркада

Учебный проект с тремя законченными мини-играми: «Пульс сети», «Эхо созвездий» и «Ритм-сад».

## Запуск

Откройте `index.html` в браузере. Для публикации включите GitHub Pages в настройках репозитория: **Settings → Pages → Deploy from a branch → main / root**.

Звуки создаются через Web Audio API, рекорды сохраняются в `localStorage`. Внешних JS-зависимостей нет.
